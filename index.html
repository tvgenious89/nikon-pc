How to use custom curve

Select point: click on a curve point or point number
Change point: select a point and move it with mouse or keys ← ↑ ↓ →
Add point: CTRL (on Mac command) + mouse click on curve
Remove point: select a point and press BACKSPACE

Editor extras

Undo / redo: Ctrl+Z / Ctrl+Y (or Ctrl+Shift+Z)
Preset Browser: tick it in the View bar to see every preset rendered on the current image
Save as preset: stores the current settings in your browser (“My presets” group in the list)
NEF files: drop a NEF to preview using its embedded JPEG

Compatibility

NCP — Capture NX, View NX, Picture Control Utility, NX Studio; DSLRs: D5000, D7000, D500, D600, D700, D800, D4, D5, D6, Df…
NP3 — Z-mount cameras (Zf, Zfc, Z5, Z6, Z7, Z8, Z9, Z50…), D6, D780 — choose 0300 for the first Z generation, 0310 for Z8/Z9-era bodies

Copy the downloaded PICCONxx.NCP / PICCONxx.NP3 to the memory card folder NIKON\CUSTOMPC\ and use the camera’s Manage Picture Control → Load/Save menu, or import it with Nikon’s desktop utilities. NP3 export follows community reverse engineering and is validated structurally — please test one file on your body before relying on it.
